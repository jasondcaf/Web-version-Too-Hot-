# Asset selection notes

This is a reduced Codex input package, **not a complete copy of the original game**.

Included: original .java source files; the Codex AGENTS.md; README and Windows runner; primary assets/rooms images used by the game.

Omitted to fit browser upload constraints: assets/preview/ (generated artwork and preview images), assets/rooms/vn_house/ (original background source collection), assets/rooms/vn_house_backgrounds.zip (duplicated archive), and compiled .class/out files.

When porting the web game, prefer the supplied assets/rooms images. If anything referenced at runtime is missing, identify it explicitly and request or recreate it, rather than silently dropping gameplay. The full original project ZIP should be retained as a backup.
